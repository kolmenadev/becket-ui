## Maverick UI Monorepo

A TurboRepo-based monorepo for a React component library and a shared design tokens package powered
by Panda CSS. Includes a Storybook app for local development and documentation.

### Packages

- `packages/tokens` — Panda CSS build output and helpers exposed as `@maverick/tokens` (css,
  patterns, recipes, JSX factory, tokens, types, and `styles.css`).
- `packages/react` — React components that consume `@maverick/tokens`. Storybook stories live
  alongside components.
- `apps/docs` — Storybook app used to develop and showcase the React components.

### Prerequisites

- Node.js 20+
- pnpm 10+ (repo uses `packageManager: pnpm@10.13.1`)

### Install

```bash
pnpm install
```

### Develop

- Run everything in dev mode via Turbo:

```bash
pnpm dev
```

- Or run Storybook directly from the docs app:

```bash
pnpm --filter docs storybook
```

- Or from the React package (reuses docs Storybook config):

```bash
pnpm --filter @maverick/react storybook
```

Storybook will start at `http://localhost:6006`.

### Build

Build all packages and apps:

```bash
pnpm build
```

### Formatting

This repo ships with a Prettier configuration. To format the codebase, first install Prettier if you
haven't already:

```bash
pnpm add -D prettier
```

Then run:

```bash
pnpm prettier --write .
```

### Using Panda CSS

This repository exposes Panda CSS artifacts through `@maverick/tokens`:

- `@maverick/tokens/css` — `css` function and `cva/sva` utilities
- `@maverick/tokens/patterns` — layout and UI patterns
- `@maverick/tokens/recipes` — recipe utilities (e.g., button)
- `@maverick/tokens/jsx` — JSX factory (e.g., `Stack`, `HStack`, etc.)
- `@maverick/tokens/styles.css` — global styles generated by Panda CSS

Import examples:

```ts
import { css } from "@maverick/tokens/css";
import { Stack } from "@maverick/tokens/jsx";
import { button } from "@maverick/tokens/recipes";
```

Add the global stylesheet once in your app or Storybook preview:

```ts
import "@maverick/tokens/styles.css";
```

### Repository scripts

From the repo root (`package.json`):

- `pnpm dev` → `turbo run dev`
- `pnpm build` → `turbo run build`
- `pnpm lint` → `turbo run lint`

From `apps/docs`:

- `pnpm --filter docs storybook`
- `pnpm --filter docs build-storybook`

From `packages/react`:

- `pnpm --filter @maverick/react storybook`
- `pnpm --filter @maverick/react build-storybook`

### Project structure

```
apps/
  docs/             # Storybook app
packages/
  react/            # React components and stories
  tokens/           # Panda CSS exports and artifacts
```
