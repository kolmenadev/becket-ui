Designing with Becket in Claude Design

Becket is a native-first design system. This post walks through the setup, the agent guide and the handoff to code. Press ⌘ K to search, and look for highlighted terms.

Setup

Install both packages and import @becket-ui/tokens/index.css once:

pnpm add @becket-ui/react @becket-ui/tokens

import '@becket-ui/tokens/index.css';
  • No provider and no theme wrapper.
  • Theme lives on <html data-theme>:
    • dark by default
    • light on request
  1. Sync the design system.
  2. Prompt a screen.
  3. Hand off to Claude Code.
