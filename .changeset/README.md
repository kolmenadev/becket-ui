# Changesets

Version and changelog for `@becket-ui/react` and `@becket-ui/tokens`.

```bash
pnpm changeset
```

That records a bump. How we choose patch/minor/major, where the GitHub Releases list lives, and how a version is cut: [docs/RELEASING.md](../docs/RELEASING.md). First public `0.1.0` still waits on [docs/PUBLISH.md](../docs/PUBLISH.md) G1. Do not `npm publish` from CI until D1 has been done once by a human.
